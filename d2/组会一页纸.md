# 组会一页纸 | 雷达目标检测公开数据验证流水线（D1–D2）

**汇报人：陈智乐　日期：2026-10-02**
课题关联：天基分布式雷达"智能目标探测"方向的工程验证线——在公开数据集上把
"原始雷达数据 → 检测 → 评测"链路跑通并量化，为后续检测网络改进提供可复现基线。

## 方法链
nuScenes v1.0-mini（scene-0061，247 sweeps）→ 点云 (range, Doppler, RCS) 直方成 RD 图 →
2D CA-CFAR（Pfa=1e-3）→ 命中点反映射 → DBSCAN 聚类 → 与官方 3D 真值匹配出 Pd / 虚警率。
D2 增量：滑动窗口（0.25–1.0 s）内多 sweep 点云按各自 ego_pose 精确刚体补偿后累积再检测。

## 主结果（同一 GT 评测体系）

| 配置 | Pd | 虚警/sweep |
|---|---|---|
| 单帧 CFAR+DBSCAN（D1 基线） | 0.017 | 0.47 |
| 多帧累积 0.5 s + DBSCAN(min=2) | 0.440 | 46.8 |
| 多帧累积 1.0 s + DBSCAN(min=2) | **0.481** | 65.1 |
| 1.0 s + 零多普勒凹口滤杂波 | 0.072 | 4.3 |

## 三个结论
1. 单帧毫米波雷达点过稀疏（CFAR 命中仅 ~50 点/sweep）是召回瓶颈；多帧累积把点密度
   提 ~9 倍，Pd 提升 28 倍（0.017→0.481），代价为虚警同量级上升。
2. CFAR 门限跨两个数量级（1e-4→3e-3）对 Pd 影响 <2 个点：虚警主要来自多径/护栏等真实
   回波，门限不是杠杆。
3. 零多普勒凹口滤静止杂波在城市场景失效：慢速/静止车辆的补偿后多普勒同样近零，
   滤杂波同时滤目标（Pd 0.481→0.072）。下一步改用簇级特征（RCS 和、速度方差、簇尺寸）
   与雷达-视觉融合做虚警抑制。

## 备注（评测口径）
GT 取最近 LIDAR_TOP sample 位姿；"雷达可见 GT" 为几何过滤（range<100 m、|az|<60°、
车辆/行人类）；匹配门限 range±2 m、方位±5°。RD 图由点云直方生成（数据集不提供原始
ADC 数据）。D1 原报 Pd=0.020 因匹配坐标系近似偏差，修正为 0.017。
